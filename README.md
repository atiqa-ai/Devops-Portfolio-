## Purpose of This Repository

This repository contains the source code for my personal portfolio website.  

It is designed to present not only the tools I use, but the **way I work**:

- I prioritize reliable, automated delivery over one-off solutions.
- I treat observability as a first-class concern, not an afterthought.
- I break problems into clear systems (infrastructure, pipelines, monitoring, security) and improve them iteratively.
- I document and structure my work so that others can understand and extend it.

The site itself is data-driven. Experience, projects, skills, and certifications live in typed modules, which keeps the interface clean and the content easy to maintain.
